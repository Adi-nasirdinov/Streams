# Java Multithreading & Synchronization Demo

A Java-based project demonstrating thread synchronization, concurrency management, and controlled execution flow across multiple threads using `wait()`, `notifyAll()`, and `synchronized` blocks.

## -------------------------------------------------------------------------------- --

## 📌 Features

- **Sequential Execution**: Ensures threads output data in a strict, predefined order rather than in a race condition.
- **Inter-Thread Communication**: Utilizes Java's built-in `wait()` and `notifyAll()` mechanisms for smooth thread coordination.
- **Scalable Architecture**: Demonstrates thread safety across multiple concurrently running threads (`Runnable` interface).

## 🛠️ Built With

- **Java 17+** (or compatible JDK)
- **Java Concurrency Utilities** (`Thread`, `Runnable`)
